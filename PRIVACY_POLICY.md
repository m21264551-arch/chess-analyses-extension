# Privacy Policy for Post-Game Chess Coach

Last updated: June 5, 2026

Post-Game Chess Coach is a Chrome extension for reviewing completed Chess.com and Lichess games.

## Data Handled

The extension may handle completed chess game data, including PGN text, move lists, game metadata, and player usernames contained in PGNs from Chess.com or Lichess.

## How Data Is Used

Game data is used only to provide local post-game chess analysis, including move grading, best-move suggestions, and analysis summaries.

The extension may request PGN data from:

- Lichess game export endpoints for the completed game being viewed.
- Chess.com public monthly PGN archive endpoints to locate the completed game being viewed.

## Local Processing and Storage

Analysis runs locally in Chrome using the Stockfish engine bundled with the extension. Analysis results are stored in Chrome local storage on the user's device so previously reviewed games can load faster.

## Data Sharing

The developer does not collect, sell, share, or transfer user data. The extension does not use tracking, advertising, analytics, or remote code.

## Contact

For questions about this privacy policy, contact the publisher using the contact email listed on the Chrome Web Store developer account.
